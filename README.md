age-calculator
What It Does
This application is an Age Calculator featuring a minimalist, pink-themed user interface. It allows users to:

Input Birth Date: Select or type a specific date of birth using a date input field equipped with a calendar picker icon.

Calculate Exact Age: Click the "Calculate" button to dynamically compute and display the precise time elapsed between the selected date and the current date.

Detailed Breakdown: Instantly view the resulting age broken down precisely into years, months, and days (e.g., “You are 25 years, 9 months and 14 days old”).
